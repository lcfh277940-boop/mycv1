--------------------------------------------------------------------------------
  3. طريقة التشغيل
--------------------------------------------------------------------------------

  الطريقة الأولى (الأسهل) — فتح مباشر:
    1. افتح مجلد HA-Digital-Portfolio
    2. انقر نقرًا مزدوجًا على ملف  index.html

  الطريقة الثانية — خادم محلي (مُستحسنة لاختبار كل الميزات):
    1. افتح Command Prompt أو PowerShell داخل مجلد المشروع
    2. نفّذ:

           python -m http.server 8000

    3. ثم افتح:

           http://localhost:8000


--------------------------------------------------------------------------------
  4. استبدال الصورة الشخصية
--------------------------------------------------------------------------------

  الصورة الحالية في  images/profile.jpg  هي صورة بديلة (Monogram) أنيقة
  بلا أي نص أو مسار ملفات ظاهر.

  لاستبدالها بصورتك:
    1. جهّز صورة عمودية بنسبة 4 : 5 (مثلًا 1000 × 1250 بكسل).
    2. احفظها في  images/profile.jpg  (بنفس الاسم) أو باسم جديد.
    3. إن اخترت اسمًا جديدًا، افتح  index.html  وغيّر قيمة src:

           <img src="images/profile.jpg" alt="صورة هديل عبدالقوي" ... />

  ملاحظة: لا تُطبع أسماء ملفات أو تعليمات داخل الصورة، لأن الصورة معروضة
  للزائر — التعليمات هنا في README فقط.


--------------------------------------------------------------------------------
  5. تعديل البيانات الشخصية
--------------------------------------------------------------------------------

  كل البيانات موجودة داخل  index.html  وتُعدَّل مباشرة من هناك:

    • الاسم (عربي) ............ في  <h1>  و  <title>  و  قسم «من أنا»
    • الاسم (علامة تجارية) .... في  .signature  و  .logo__word
    • المسمى المهني ............ في  مصفوفة  ROLES  داخل  script.js
    • رقم الهاتف / الواتساب .... ابحث عن  0557123774  و 966557123774
    • البريد الإلكتروني ........ ابحث عن  lcf277940@gmail.com
    • نصوص الأقسام .............. #about  #skills  #projects
                                #education  #interests  #vision
    • تفاصيل المشاريع .......... داخل  .project__detail

  عند تعديل نص المسمى المهني لا تنسَ تحديث  ROLES  في  script.js
  (المفتاح  ar  والمفتاح  en) ليطابق النص الجديد مع تأثير الكتابة.


--------------------------------------------------------------------------------
  6. تعدد اللغات (العربية / English)
--------------------------------------------------------------------------------

  زر اللغة في شريط التنقل يبدّل بين العربية والإنجليزية فورًا:
    • تبديل الاتجاه تلقائيًا (RTL ⇄ LTR).
    • تبديل خط العناوين تلقائيًا (El Messiri ⇄ Cormorant Garamond).
    • ترجمة كامل النصوص: الأقسام، البطاقات، المشاريع، المهارات، التعليم،
      الاهتمامات، الرؤية، التواصل، والتذييل.
    • تحديث عنوان الصفحة ووصفها (SEO) ووسوم Open Graph و Twitter.
    • حفظ اللغة المختارة في LocalStorage.
    • معاملات الرابط:  ?lang=en   و  ?static=1  (تعطيل الحركات).

  لتعديل نص إنجليزي: في  script.js  ابحث عن  const TRANSLATIONS = { en: { ... } }
  وعدّل النص المقابل للمفتاح. المفاتيح مطابقة لخصائص  data-i18n  في  index.html.


--------------------------------------------------------------------------------
  7. تعديل الهوية البصرية
--------------------------------------------------------------------------------

  كل ألوان الموقع معرَّفة كمتغيّرات CSS في أعلى  style.css  داخل  :root :

      --rose            #E9A7B0    Soft Rose
      --rose-soft       #DE9FB4
      --berry           #5A2740    Deep Berry
      --berry-deep      #3F1A30
      --blush           #F8E9EA    Blush Mist
      --metallic        #D3C6BC    Metallic Silver
      --metallic-line   rgba(...)
      --cream           #FDF8F4    Cream Pearl
      --mist            #EFE4E6
      --accent          var(--rose)
      --accent-strong   #C97C8C
      --heading         var(--berry)

  الوضع الليلي معرَّف في كتلة  [data-theme="dark"]  أسفلها مباشرة.
  لتغيير خط العناوين:  --font-display  (يتبدّل تلقائيًا حسب اللغة).
  لتغيير خط التوقيع:  "Great Vibes", "Parisienne", cursive  في  .logo__word  و  .signature  و  .medallion__word.


--------------------------------------------------------------------------------
  8. المشهد ثلاثي الأبعاد (3D Scene)
--------------------------------------------------------------------------------

  خلفية الواجهة الرئيسية مشهد ثلاثي الأبعاد مبني بالكامل بـ CSS 3D
  (لا صور إضافية ولا مكتبات):
    • شاشة صغيرة تعرض HTML و CSS
    • كمبيوتر محمول مصغّر يعرض كود JavaScript
    • نافذة أوامر شفافة عائمة
    • رمز الذكاء الاصطناعي (شبكة عصبية) ورمز تحليل البيانات
    • شارات HTML / CSS / JS
    • حروف وأرقام برمجية مضيئة
    • مكعّب وحلقة ومعيّن ثلاثي الأبعاد
    • لوحة مفاتيح مصغّرة
    • جسيمات ضوئية متطايرة
  + Parallax خفيف يتبع حركة المؤشر + إضاءة متغيّرة ناعمة.
  + طبقة تعتيم (scrim) تضمن وضوح النص فوق العناصر.

  لتخفيف المشهد على الشاشات الصغيرة أو تعطيل الحركات بالكامل:
    @media (prefers-reduced-motion: reduce)  أو  ?static=1


--------------------------------------------------------------------------------
  9. المزايا التفاعلية المُنفّذة
--------------------------------------------------------------------------------

   1. التبديل بين الوضع الليلي والنهاري (زر الشمس/القمر)
   2. حفظ تفضيل الوضع في LocalStorage
   3. قائمة جوال تفاعلية مع طبقة تعتيم وإغلاق بـ Escape
   4. تمرير سلس بين الأقسام مع تعويض ارتفاع شريط التنقل
   5. شريط تقدم القراءة أعلى الصفحة
   6. تحديد القسم النشط + مؤشر ذهبي متحرك
   7. ظهور العناصر تدريجيًا عبر IntersectionObserver
   8. تأثير كتابة متحرك للمسمى المهني (يتبدّل حسب اللغة)
   9. تأثيرات Tilt ثلاثي الأبعاد + Hover على البطاقات
  10. زر العودة إلى أعلى الصفحة مع حلقة تقدّم
  11. طباعة/تصدير PDF عبر نافذة الطباعة + تنسيق طباعة احترافي
  12. احترام إعدادات "تقليل الحركة"
  13. مبدّل لغة عربي/إنجليزي كامل مع تبديل الاتجاه والخط والوسوم
  14. Parallax خفيف للمشهد ثلاثي الأبعاد مع حركة المؤشر
  15. نافذة تفاصيل تفاعلية لكل مشروع مع حصر التركيز
  16. تلميحات منبثقة (Toast) عند تبديل الوضع/اللغة وعند الطباعة


--------------------------------------------------------------------------------
  10. إمكانية الوصول (Accessibility)
--------------------------------------------------------------------------------

  • عناصر HTML5 دلالية:  header / nav / main / section / article / footer
  • نص بديل (Alt) لكل صورة (و alt="" للصور الزخرفية)
  • جميع الأزرار والروابط قابلة للوصول بلوحة المفاتيح (Tab)
  • حالة تركيز واضحة  (:focus-visible)
  • حصر التركيز داخل نافذة تفاصيل المشروع
  • سمات  aria-label / aria-pressed / aria-expanded / aria-valuenow
  • عنوان H1 واحد فقط، وترتيب عناوين صحيح
  • تباين ألوان مناسب في الوضعين النهاري والليلي
  • خصائص  lang  و  dir  تُحدَّثان تلقائيًا مع تبديل اللغة


--------------------------------------------------------------------------------
  11. تحسين محركات البحث (SEO)
--------------------------------------------------------------------------------

  • وسوم  title / description / keywords / author / canonical
  • وسوم Open Graph و Twitter Card (بالعربية والإنجليزية)
  • بيانات منظّمة JSON-LD (نوع Person) داخل <head>
  • أبعاد الصور محددة (width/height) لتقليل Layout Shift
  • تحميل كسول (loading="lazy") للصور خارج الشاشة الأولى
